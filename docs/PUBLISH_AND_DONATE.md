# Как запустить донат и опубликовать игру

Порядок важен: геймпассы привязаны к опубликованной игре, поэтому сначала
игра публикуется **закрытой**, потом создаётся донат, и только потом игру открывают для всех.

---

## Шаг 1. Подготовка в Studio

1. Открой место **MOG** в Roblox Studio.
2. Подключи Rojo: **Plugins → Rojo → Connect** (сервер `rojo serve` должен быть запущен).
   Всё, что есть в проекте, должно попасть в место: скрипты в ServerScriptService / StarterPlayer / ReplicatedStorage.
3. Проверь, что в **ReplicatedStorage → TierHeads** лежат `Head1` … `Head8`.
4. **Home → Game Settings**:
   - **Avatar** → Avatar Type: **R15** (игра рассчитана на R15).
   - **Security** → включи **Enable Studio Access to API Services** (для теста сохранений в Studio).
5. Нажми **Play** и проверь, что игра запускается без красных ошибок в Output.

> Тестовые штуки (кнопка **DEV**, «всё куплено», «все предметы открыты») работают **только в Studio**.
> В опубликованной игре их не будет — ничего выключать не нужно.

## Шаг 2. Первая публикация (закрытая)

1. **File → Publish to Roblox** (или **Alt+P**).
2. Выбери **Create new experience** (если игра ещё не опубликована).
3. Название: `Looksmax Simulator`, описание, жанр (**Simulation**). Создатель — твой аккаунт.
4. Нажми **Create**. Игра появится на create.roblox.com, но пока она **Private** — её видишь только ты.

## Шаг 3. Создание доната (геймпассов)

Нужны два пасса (их уже ждёт кнопка **VIP** в игре):

| Пасс | Название | Цена | Что даёт |
|---|---|---|---|
| Vip | VIP Trainers | 249 R$ | Золотые тренажёры x6 вместо x3 |
| X2 | x2 Rating & Glow | 199 R$ | Каждый клик даёт вдвое больше |

Для **каждого** пасса:

1. Открой **create.roblox.com** → **Creations** → твоя игра.
2. Слева **Monetization → Passes** → **Create a Pass**.
3. Загрузи картинку 512×512 (иконка пасса, без текста-ссылок и логотипов чужих сайтов),
   впиши **Name** и **Description** → **Create Pass**.
4. Открой созданный пасс → **Sales** → включи **Item for Sale** → поставь цену → **Save Changes**.
5. Скопируй **ID пасса**: это число в адресной строке
   (`.../passes/1234567890/...`) или пункт **Copy Asset ID** в меню «⋯» у пасса.

Пришли мне оба ID в формате:

```
Vip = 1234567890
X2  = 9876543210
```

Я впишу их в `Config.GamePasses`, и кнопки в окне VIP станут настоящими
(сейчас там надпись «Скоро»). Покупка включается сразу, без перезахода.

> Роблокс забирает **30%** с каждой покупки. Вывод денег (DevEx) — от 30 000 заработанных Robux,
> нужен подтверждённый аккаунт и возраст 13+.

## Шаг 4. Финальная публикация и открытие игры

1. После того как я обновлю код — подключи Rojo ещё раз, чтобы изменения попали в место.
2. **File → Publish to Roblox** (публикация в ту же игру, уже без создания новой).
3. На create.roblox.com → твоя игра:
   - **Experience Questionnaire** (опросник о содержании) — заполни честно:
     насилия/крови нет, реальных денег-азарта нет, общение — стандартный чат.
   - **Settings / Configure** → **Privacy / Access** → **Public**.
   - Загрузи **иконку** (512×512) и 1–3 **скриншота / thumbnail** (1920×1080) — без ссылок и чужих логотипов.
   - **Places → Start Place → Server size**: **32** игрока.
4. Если Роблокс попросит подтвердить аккаунт (телефон / почта / ID) перед публичным запуском — это его стандартная проверка.

Готово — игра в поиске Роблокса.

## Важно про модерацию

- Картинки, которые ты загружаешь (иконки, превью, текстуры), проверяет автоматика.
  Не используй ссылки, QR-коды, названия соцсетей, чужие логотипы.
- Если снова придёт предупреждение по ошибке — подавай апелляцию через **Appeals Portal**:
  кратко объясни, что это за картинка (иконка геймпасса / текстура модели) и что ссылок в ней нет.
